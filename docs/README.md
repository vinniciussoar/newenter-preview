# NEWENTER — Inteligência Empresarial · Documentação Estratégica

> **Posicionamento:** plataforma integrada de Inteligência Empresarial, Governança e Performance.
> **Não** um escritório de contabilidade. A referência é Deloitte, PwC, KPMG, EY, Accenture, McKinsey e BCG.
>
> **Mensagem central:** _"Transformamos obrigações em inteligência para decisões empresariais."_
> **Conceito-produto:** **ONE BUSINESS BOARD** — uma única visão executiva que conecta seis frentes do negócio.

---

## Conceito

O visitante deve sentir que está diante de uma **estrutura de gestão empresarial** — um _Board Room Digital_, centro de controle e inteligência — e não de um prestador operacional. Tudo no projeto reforça sete atributos:

`Governança · Inteligência · Segurança · Controle · Autoridade · Performance · Sofisticação executiva`

## Público-alvo (tomadores de decisão)

CEO · CFO · COO · Diretores · Conselheiros · Acionistas · Family Offices · Gestores Financeiros.

**Empresas:** Comércio Exterior, importadores, exportadores, agentes de carga, holdings, hotelaria, grupos empresariais, empresas em expansão.

## Tom de voz

| Proibido | Obrigatório |
|---|---|
| Linguagem jovem | Linguagem executiva |
| Emojis | Linguagem institucional |
| Marketing agressivo | Discurso consultivo |
| "Economize agora" / "Somos os melhores" | Objetividade |
| Promessas exageradas | Inteligência estratégica |

> O texto deve parecer escrito por um **ex-diretor financeiro**, não por um vendedor.
